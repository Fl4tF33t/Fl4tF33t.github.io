Boids

A boids simulation recreates flocking behaviour by combining simple local rules such as separation, alignment, and cohesion. Together, these rules let individual agents move as a coordinated group without relying on a central controller.

  • Focus: Flocking and emergent behaviour
  • Techniques: Separation, alignment, and cohesion
  • Goal: Simulating coordinated agent movement

Overview

This project explores how simple steering behaviours can produce convincing group movement and how the simulation can be structured for many agents.

View Source Code

Implementation

The simulation was built in Rust using Bevy's Entity Component System (ECS) framework. Each boid is represented as an entity with components storing its position, velocity, and movement parameters, while systems handle flocking behaviour and update movement each frame.
